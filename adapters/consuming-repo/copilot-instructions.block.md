## Pico go-to-market

Customer-facing text in this repository is governed by the Pico brain at `gtm-brain/`. Read `gtm-brain/AGENTS.md`, `gtm-brain/rules/do-not-say.md`, and `gtm-brain/rules/feature-status.md` before suggesting UI strings, emails, docs, or release notes.

1. A capability that is not SHIPPED is never written in the present tense.
2. A number, customer name, or quote that is not in the brain is never written.
3. `python3 gtm-brain/tools/brain.py lint` passes before the suggestion is offered.

# Sources

The original GTM build, kept so any ledger line can be traced to the artifact it came from. When a claim is questioned, the argument ends by opening the source.

- `extracted/pico-core-features-overview.md`: the product document, 2026-11-02. The only product source.
- `extracted/gtm-brief.md`: the discovery brief, with the narrowing drill and the proof rules.
- `extracted/decisions-source.md`: the 56-entry decision log as built, with the launch calendar and budget.
- `extracted/merchants/`: the nine merchant dashboards, the lead magnet spec, the scorecard brief, and the deck outline.
- `extracted/implementers/`: the same set for implementers.
- `research/`: the research pass, every vendor fact with its URL and the date checked.

These files are the build's working record and contain internal decision codes and method notes. They are never loaded for copy. The distilled, governed versions live in `context/`, `rules/`, `reference/`, and `ops/`.

Raw binaries (XLSX, DOCX, PDF, the walkthrough HTML, the Google folder) stay in github.com/Saasrelaunchdev/PicoFindsGTMBuild.

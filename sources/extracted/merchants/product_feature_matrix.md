# Run 1, Dashboard 1: Product Feature Matrix, Shopify merchants

Pico's 22 stated features and 12 candidates, scored for demand and competitiveness against the Run 1 slate and its 22-name watchlist. Global market, USA first. The GCC is a secondary market for later and is noted where it changes a score. Evidence: `research/2026-11-03-run-1-step-1-1-feature-demand.md`, plus Step 0 and Steps 2.1 and 2.7. Built 2026-11-03 with gtm-builder v3.1, Steps 1.2 to 1.7.

Scores are analyst judgments made from the cited evidence. They are not measurements of Pico, and a candidate is never a claim: a candidate in the Hero quadrant is a roadmap finding.

**What the matrix says.** Pico's stated features fall mostly into Table Stakes and Commodities. Its differentiators (sandbox, setup skill, right to left combination, custom API, Shopware, local payment) sit where US merchant demand is low. The only Hero is cost the merchant can predict, which became a Hero once the two pricing decisions were made (D24, D25). The weightiest roadmap rows are table stakes Pico lacks (C1, C5, C6, C8), and the one candidate that could differentiate is holdout measurement (C9).

## Sheet: Demand_Drivers

### Step 1.6: The demand driver

**The Shopper Words Test.** Rule 2 of the skill ("reveal a problem that can only be solved by Pico") holds only in a narrowed form, stated below. Shopify already shows search-bar zero results, so the problem Pico reveals is the one inside conversational requests.

| Attribute | Description |
|---|---|
| What it is | A free first session: the merchant installs Pico on the Free plan (50 conversations), then types 10 to 20 requests the way their shoppers ask, for example the terms in Shopify's own "Searches with no results" report, rephrased as questions, or questions from customer emails. Pico's Analytics page then lists the requests that returned no products or few clicks |
| Immediate value | A list of findability gaps in the merchant's own catalog in the first session: requests that found nothing and requests that found products nobody would click |
| How it helps in problem identification | It separates a missing product from a product described in words the shopper did not use, which is the narrowed claim in `GTM-BRIEF.md` Section 5 |
| How it exposes the need to use Pico | The gap reappears every day that shoppers ask in their own words. Shopify's report covers the search bar. Requests typed into an assistant are captured only while an assistant is running, so the test turns into the reason to keep Pico on |
| ICP fit | ICP Level 1 and Level 2, US first: catalogs with many similar or technical products (Sports, Health, Pets, Autos, Consumer Electronics) |
| Conversion role | Moves the merchant from install to activation (embed on, catalog synced, first conversations) inside the trial, and shows Analytics before the trial ends |
| Top-of-funnel use case | The App Store listing's first call to action, a content guide ("run the Shopper Words Test on your store"), and the audit implementers run on client stores in Run 2 |

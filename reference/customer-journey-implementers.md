## Stage 4, the engagement step by step

| Step | What happens | Platform rule or blocker | Intervention |
|---|---|---|---|
| 1. Recruit | Upwork fixed-price post, Fiverr brief or gig order, cold email, LinkedIn message | CAN-SPAM for email, no automation on LinkedIn | Scope and fee in the first line, messages by hand |
| 2. Accept | The implementer accepts scope and the $150 fee | Upwork keeps payments on Upwork for 24 months, Fiverr pays only by order | Pay on the platform where found |
| 3. Sandbox test | Sandbox store and setup skill | None | Setup walkthrough video |
| 4. Client permission | If a client store is used, the merchant agrees in writing | The client is the budget holder | One-page permission template, a development store as fallback |
| 5. Install | Checklist or setup skill | App embeds are off by default after install | Checklist prompts, a setup-time log |
| 6. Shopper Words Test | Phrases from the client's customers, read in Analytics | None | The findings template |
| 7. Feedback | What worked, what broke, setup time | None | Required fields in the form |
| 8. Payment | Within 7 days of the completed form, or milestone or order release | As step 2 | Pay on time, every time |
| 9. Interview | Optional, $75 | Same platform rule | Offer inside the same engagement |
| 10. Case study permission | Optional, from merchant and implementer | The proof rules | Exact wording to be published, in the form |
| 11. Partnership invite | From week 6: 25% for 24 months, 30% for lead partners | No invitation inside Fiverr. Upwork payouts stay on Upwork for 24 months | Open the program on Pico's own page, email, and LinkedIn. Counsel review in week 5 |

## Key insights
- **Critical success factors:** fee and scope in the first message. The install works first time on a real store. Client permission handled up front. Partnership terms ready before the first sessions end.
- **Blockers:** platform rules. A new program with no record, so the first payout on the 15th must land. Client permission. One store per plan until the workspace ships.
- **Accelerators:** start with freelancers who already sell installs for about $100. Shorten every session with the sandbox and setup skill. Turn the findings list into the Client Store Findability Audit. Switch on free development store testing before outreach starts.

# Pages, finished long-form assets

Shipped copy lives here, one file per live asset, named after its surface, for example `pages/app-store-listing.md` once the listing is approved and live.

The rule is update rather than rewrite, because a shipped page carries approvals a fresh draft does not. Every file here is listed in `ops/asset-index.md` with its live location, so an amendment can find every page that carries an old claim.

Nothing has shipped on 2026-11-04. The first candidates, in launch order: the App Store listing (week 3), the merchant scorecard landing page (week 3), the technical one-pager (after the week 1 speed test), and the partner page (week 6).
